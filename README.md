:. Nirmaan Hetu
============

A modern web platform connecting builders and property owners - from showcasing portfolios to finalizing property deals. 

Features
--------

*   Builder & property owner dashboards
    
*   Secure authentication with protected routes
    
*   Portfolio showcasing for builders
    
*   Property comparison for owners
    
*   AI assistant for home-related queries (Gemini 1.5 Flash)
    
*   Image upload & management using Cloudinary
    
*   Optimized performance using React memoization
    
*   Smooth and responsive user experience
    

Tech Stack
----------

*   **Frontend:** React.js
    
*   **Backend:** Node.js, Express.js
    
*   **AI Integration:** Gemini 1.5 Flash
    
*   **Storage:** Cloudinary
    
*   **APIs:** REST APIs
    

How It Works
------------

*   Builders create profiles and showcase their completed projects
    
*   Property owners browse and compare listings digitally
    
*   AI assistant helps users with property/home-related questions
    
*   Secure dashboards ensure safe and structured interactions
    
*   Cloudinary handles media uploads for fast and optimized delivery
